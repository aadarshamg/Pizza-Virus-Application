# Pizza Delivery App

A Vite + React + Tailwind CSS demo application implementing:

- Design system tokens (color + typography)
- Reusable UI components (`Button`, `PizzaCard`, `Header`, `Footer`)
- Home page with hero and featured pizzas
- Menu page with search + category filtering
- Cart state management via React Context
- Checkout form with order summary and total calculations

## Run locally

```bash
npm install
npm run dev
```
